## Protocol & Tasks
1. Scan QR code on laptop using personal phone camera.
2. Tap "Begin the séance" and observe phone-laptop link.
3. Complete one physics experiment (Pendulum or Spin & Find the Chip).
4. Review the Oracle verdict, test "Ask the Spirit", and view the "Haunted Lab Notebook" report.
5. Switch to Banshee Choir and test audio loop gesture.
