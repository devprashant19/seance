## 2. Screen Reader & Live Regions

- **Polite Live Regions**: Error dialogs and Oracle status changes announce via `role="alert"` and `aria-live="polite"`.
- **Throttling**: High-frequency 60 Hz physics updates are isolated to canvas; screen readers receive discrete milestone announcements ("Calibrated", "Recording complete", "Results computed").
- **Alternative Text**:
  - QR Code contains `aria-label="QR code for https://..."` and adjacent plain-text room code copy.
  - Avatar indicators convey mood and state via explicit text strings (e.g. "Calm", "Uneasy", "Restless", "Fading"), never color alone.
  - Formulas and units feature descriptive textual representations (e.g., `m/s²` -> "metres per second squared").

## 3. Contrast & Theme Tokens

- High-contrast typography on dark grimoire background:
  - Headers / Titles: `#e2b8ff` / `#f0f4ff` on `#0a0a1a` (Contrast > 12:1).
  - Body Text: `#ccd0e0` on `#0a0a1a` (Contrast > 9:1, well above 4.5:1 requirement).
  - Muted Text / Labels: `#99aabb` on `#0a0a1a` (Contrast > 6.2:1).
  - Action Buttons: High contrast `#ffffff` on `#334477` (Contrast > 5.5:1).

## 4. Reduced Motion (`prefers-reduced-motion`)

- Avatars switch from 3D rotating LatheGeometry to static 2D vector ghost (`PoltergeistFlat`).
- Pulsing summoning circles and breathing animations are disabled when reduced-motion is requested.
- Exorcism noise particle wisps are replaced by subtle static boundary bands.
