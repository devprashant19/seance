# Testing rules (Séance)

## Stack
- Vitest (Node environment for `seance-core`, `seance-relay`, `seance-mcp`; jsdom only where a component needs it).
- fast-check for property-based tests. Playwright for end-to-end.

## File naming
| Kind | Name |
|---|---|
| Unit | `<module>.test.ts` |
| Property-based | `<module>.property.test.ts` |
| Type-level | `<module>.types.test.ts` (uses `expectTypeOf` and `// @ts-expect-error`) |
| Transport contract | `<transport>.contract.test.ts` calling `runSpiritContract` |
| Trace replay regression | `apps/poltergeist-lab/test/traces/<trace-id>.replay.test.ts` (generated by hook H2 — regenerate, never hand-edit) |

## Property-based tests
- One `fc.assert` per `**Property:**` in a spec; name the test after the spec property id (e.g. `"P1: pendulum g within reported uncertainty"`).
- Reuse arbitraries from `seance-core/testing` (`arbJitteredSine`, `arbDampedSine`, `arbTrace`, …). Add new ones there, not inline.
- `numRuns` 200 by default; honour `process.env.FC_NUM_RUNS`.
- Compare floats with `closeTo(a, b, { rel, abs })`. Never loosen a tolerance without a comment explaining the physics or numerics.
- Forward-model → inverse pattern for physics: generate parameters, synthesise a noisy trace with the forward model, run `analyze`, assert the recovered value is within the reported uncertainty (or a stated bound).
- When a property fails, keep the shrunk counter-example as a regular unit test after fixing the bug.

## Trace-replay regression pattern (hook H2 generates this)
```ts
import { readFileSync } from 'node:fs';
import { decodeTrace } from 'seance-core/trace';
import { getExperiment, raw } from 'seance-core';
import 'poltergeist-lab/experiments';   // registers experiments (exact entry decided in Phase 5)
const trace = decodeTrace(readFileSync(new URL('../traces/<id>.seance', import.meta.url), 'utf8'));
it('<experiment> on <id> stays within tolerance', () => {
  const r = getExperiment(trace.experiment!)!.run(trace, trace.inputs as any);
  expect(Math.abs(raw(r.primary.value) - trace.expected!.value)).toBeLessThanOrEqual(trace.expected!.tolerance);
});
```
Only traces with a real, measured `expected` block get a regression test. Never invent expected values.

## Determinism
- Seed every PRNG (mock transport, arbitraries). Use fake timers (`vi.useFakeTimers()`) for anything time-based; the mock spirit has a `manual` clock.
- No network in unit tests — use `fake-relay.ts` for the phone bridge.

## Hygiene
- Tests must not depend on execution order or wall-clock time.
- Each new public function gets at least one test in the same PR.
- Keep fixture traces small (< 500 KB); trim to the interesting window.
